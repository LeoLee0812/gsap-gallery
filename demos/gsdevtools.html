GSDevTools · 动画调试面板

调动画最烦的是「每改一个参数就得刷新页面重看一遍，还只能看那 0.3 秒的关键部分」。 GSDevTools 在页面底部装了一个带时间轴刻度的播放器：能拖进度、能变速、能循环某一段、能按标签跳转。
看页面最下方那条控制条。

底部这条控制条能做什么：
  • 拖动进度条——精确停在任意一帧，看清那一刻元素到底在哪
  • 时间轴上的标签点——直接跳到 logo / title / desc / chips 任意一段
  • in / out 标记——框定一个区间循环播放，反复打磨某 0.5 秒
  • 速度下拉——0.1 倍速慢放，看清快动作里到底发生了什么
  • 左侧下拉框——页面里有多条动画时，切换调试对象
gsap.registerPlugin(GSDevTools);

// 给要调试的动画起个 id，面板的下拉框里就能选到它
const tl = gsap.timeline({ id: "intro" });
tl.addLabel("logo")
  .from("#logo", { scale: 0, rotate: -180, duration: 0.8, ease: "back.out(1.7)" })
  .addLabel("title")
  .from("#title", { y: 30, opacity: 0, duration: 0.6 })
  // …

// 一行创建面板
GSDevTools.create({
  animation: "intro",   // 传 id 或动画实例；不传则调试全局时间轴
  globalSync: true,     // 让面板与全局时间轴同步
  persist: true         // 刷新页面后保留上次的进度和速度设置
});
⚠️ 上线前一定要删掉 GSDevTools。 它是开发期工具，会往页面注入 DOM 和监听器，也会拖慢性能。 常见做法是用环境变量包一层：if (import.meta.env.DEV) GSDevTools.create()， 这样生产构建时会被自动摇树掉。
