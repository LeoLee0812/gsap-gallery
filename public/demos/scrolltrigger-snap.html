滚动吸附 snap

不加 snap 时，松开滚轮页面会随便停在某个尴尬位置——半张图、半段字。 snap 会在滚动停下的瞬间自动补一小段动画，把页面吸到最近的整点上。 整屏叙事、分步引导必备。
往下滚，随便在哪松手，看它自己吸过去。

↓
01
滚动开始
整段被 pin 住，你继续滚动，内容在原地切换——这是 pin + scrub 的经典组合。
02
吸附到整点
试着在两段中间松开滚轮，页面会自己补一小段滚动，落到最近的段落上。
03
吸附的时长和缓动可调
duration 设成区间 { min, max } 时，距离近就快、距离远就慢，比固定时长自然得多。
04
也能吸到指定点位
左上角切到「指定点位」：吸附点变成不均匀的 [0, 0.15, 0.55, 1]，用于强调某几个关键帧。
05
关掉对比一下
切到「关闭吸附」再滚一遍，就能体会到那种「停在半路」的不适感是从哪来的。
ScrollTrigger.create({
  trigger: ".spacer",
  start: "top top",
  end: "bottom bottom",
  pin: ".pinbox",
  scrub: 0.6,

  snap: {
    // 数字 = 均分成几段（1/4 即 0, .25, .5, .75, 1 五个吸附点）
    // 数组 = 指定任意点位；"labels" = 吸到时间轴标签上
    snapTo: 1 / 4,
    // 区间写法：距离近吸得快，距离远吸得慢
    duration: { min: 0.2, max: 0.6 },
    delay: 0.05,
    ease: "power2.inOut"
  }
});

三种 snapTo 写法：数字（均分）、数组（指定点位）、"labels"（吸到时间轴上的标签，做章节导航最合适）。
delay 别设太大，否则用户会觉得「页面卡了一下才动」；0.05~0.15 之间比较自然。
手机上慎用：触摸滚动本身有惯性，再叠一层吸附容易打架，必要时用 matchMedia 只在桌面启用。
