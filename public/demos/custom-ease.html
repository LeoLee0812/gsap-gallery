CustomEase · 自己画缓动曲线

内置的 power / back / elastic 覆盖不了所有需求。CustomEase 让你用任意 SVG 路径定义速度曲线—— 想在中途停顿一下、来回摆两次、突然加速，都可以画出来。

复杂曲线（多控制点，用 SVG path 描述）
gsap.registerPlugin(CustomEase);

// 写法一：四个数字，和 CSS cubic-bezier() 完全一致
CustomEase.create("myEase", ".17,.67,.83,.67");
gsap.to(box, { x: 400, ease: "myEase" });

// 写法二：任意 SVG path，可以有任意多个控制点
// 这条曲线会先冲过头、回落、再冲过头一次，做出「弹两下」的效果
CustomEase.create("hop",
  "M0,0 C0,0 0.056,0.442 0.175,0.442 0.294,0.442 0.332,0 0.332,0 " +
  "0.332,0 0.414,1 0.671,1 0.991,1 1,0 1,0");

// 从 GSAP 的 Ease Visualizer 网站可以直接画完复制这段 path

什么时候真的需要 CustomEase：设计师给了一条具体的动效曲线、要和 App 端的动画手感对齐、 或者内置 ease 就是差那么一点意思的时候。日常 90% 的场景 power2.out 就够了，别过度设计。
path 的坐标系：x 从 0 到 1 是时间，y 从 0 到 1 是进度。y 超出 0~1 就是「冲过头」，这正是回弹效果的来源。
