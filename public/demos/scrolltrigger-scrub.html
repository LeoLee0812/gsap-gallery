scrub · 把动画绑死在滚动条上

普通触发是「滚到这儿就播完」，scrub 是「你滚多少它走多少」——停下它就停，往回滚它就倒着走。 产品 360° 展示、图表随滚动生长都靠这个。
下面三条轨道共用同一段滚动区间，区别只有 scrub 的取值。快速滚动时差异最明显。

↓
scrub: true
完全同步，一帧不差。手感最「硬」，快速滚动时会显得生硬。
scrub: 1
播放头用 1 秒追赶滚动位置。有阻尼感，是绝大多数场景的最优解。
scrub: 3
追赶得更慢，明显拖尾。停止滚动后还会继续走一段，适合做「慵懒」的氛围感。
滚动进度
0% 
// scrub 只能加在顶层 tween / timeline 上，不能加在时间轴内部的子动画上
gsap.to(".runner", {
  x: 600,
  // ease 在 scrub 模式下通常要设成 "none"
  // 否则「滚动位置 → 动画进度」之间会再套一层曲线，手感变得不可预测
  ease: "none",
  scrollTrigger: {
    trigger: ".section",
    start: "top top",
    end: "bottom bottom",
    scrub: 1          // true = 硬同步；数字 = 追赶所需秒数
  }
});

两条实战经验： ① scrub 动画的 ease 一律写 "none"，让滚动距离和动画进度保持线性关系；想要节奏感就调 start/end 的区间长度。
② 数字型 scrub 会在滚动停止后继续补间，所以 onScrubComplete 才是「真正播完」的回调，onComplete 在这里不好使。
