ease: power2.inOut

ScrollToPlugin · 平滑锚点

浏览器原生的 scroll-behavior: smooth 时长写死、缓动写死、没法中途取消、也没有完成回调。 ScrollToPlugin 把「滚动位置」当成一个可以补间的普通属性——于是它拥有 GSAP 的一切能力。
点上面的导航试试。

01 为什么不用原生 smooth gsap.to(window, { scrollTo })

滚动位置一旦变成可补间属性，你就能给它设 duration、ease、onComplete，甚至放进时间轴里和别的动画一起编排。 最实用的一点是：用户一碰滚轮就能立刻取消，不会出现「我想停它偏要滚完」的糟糕体验。 

gsap.registerPlugin(ScrollToPlugin);

gsap.to(window, {
  duration: 1,
  scrollTo: "#s3",        // 选择器、元素、数字像素、"max" 都行
  ease: "power2.inOut"
});

02 offsetY：别被固定头部挡住 { y, offsetY }

页面有 fixed 导航栏时，直接滚到目标元素会让标题藏在导航栏底下。 offsetY 就是给这个头部留的余量——本页导航高约 52px，所以统一留了 70。 

gsap.to(window, {
  duration: 1,
  scrollTo: { y: "#s2", offsetY: 70 },  // 顶部预留 70px
  ease: "power2.inOut"
});

03 相对滚动与快捷值 "+=600" / "max"

除了具体目标，还能写相对量和关键字。"max" 会自动算出页面能滚到的最底部， 比手写 document.body.scrollHeight 省事且不会算错。

04 滚的不一定是窗口 gsap.to(container, { scrollTo })

第一个参数换成任意可滚动的 DOM 容器，就能在弹窗、侧边栏、聊天记录里做平滑滚动—— 聊天应用「跳到最新消息」就是这么写的。

05 用户一碰滚轮就该让路 autoKill: true

autoKill 是这个插件最该记住的选项。开启后，只要用户在补间过程中自己滚了一下， 动画立刻停手把控制权还回去。不开的话就会出现「我想停下来看，页面非要把我拖走」的抢夺感。 

gsap.to(window, {
  duration: 1.5,
  scrollTo: { y: "#s1", autoKill: true },
  ease: "power2.inOut",
  // 被用户打断时也会触发，可用来复位状态
  onInterrupt: () => console.log("用户接管了滚动")
});
