物理模拟 · Physics2D / PhysicsProps

抛物线、重力下落、摩擦减速——这些不该用 ease 硬凑， 直接给初速度、角度、重力、摩擦力，让 GSAP 按物理公式算轨迹。 撒花、粒子、烟花、落叶全靠这两个插件。点任意区域触发。

给定速度 + 角度 + 重力，自动算出抛物线轨迹。撒花、爆炸、喷泉的标准解法。

PhysicsProps · 任意属性做物理
不局限于 x/y，任何数值属性都能给它速度和加速度——旋转、缩放、透明度都行。
点击让它翻滚下落
gsap.registerPlugin(Physics2DPlugin, PhysicsPropsPlugin);

// ── Physics2D：给速度、角度、重力，自动算抛物线 ──
gsap.to(particle, {
  duration: 2,
  physics2D: {
    velocity: 600,        // 初速度（像素/秒）
    angle: -75,           // 发射角度（度，-90 是正上方）
    gravity: 1200,        // 重力加速度（像素/秒²）
    friction: 0           // 空气阻力 0~1
  },
  // 物理只管位置，旋转和淡出还是照常写
  rotation: "random(-540, 540)",
  opacity: 0,
  ease: "none"
});

// ── PhysicsProps：给任意属性配速度和加速度 ──
gsap.to(box, {
  duration: 2,
  physicsProps: {
    y:        { velocity: 0,   acceleration: 900 },   // 自由落体
    rotation: { velocity: 320, friction: 0.06 },      // 边转边被摩擦力拖慢
    scale:    { velocity: -0.4, acceleration: 0.3 }
  }
});

Physics2D 和 PhysicsProps 怎么选：
· Physics2D —— 专为「二维空间里的抛射」优化，参数是速度/角度/重力，最符合直觉。做撒花、爆炸、喷射选它。
· PhysicsProps —— 更通用，给任意属性单独配一组物理参数。想让 rotation 有惯性、让 opacity 加速衰减，只能用它。

物理动画有个天然限制：无法预知终点。所以它不能倒放、不能 seek 到任意时刻。 如果你需要精确控制结束位置，该用 InertiaPlugin（它可以指定 end 值）而不是物理插件。
角度是度不是弧度，且 -90 指向正上方（因为屏幕 y 轴向下）——这两个几乎人人第一次都要栽一下。
