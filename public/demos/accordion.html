什么是 GSAP？
GSAP（GreenSock Animation Platform）是一个高性能的 JavaScript 动画库，能够精确地为任意 DOM 属性、CSS、SVG、Canvas 等创建流畅动画，被广泛用于网页交互与动效设计。
高度从 0 到 auto 怎么平滑过渡？
CSS 无法直接对 auto 高度做过渡。本示例先让 GSAP 把目标高度设为 "auto" 测量真实高度，再回退到具体像素值进行补间，从而实现平滑展开与收起。
手风琴模式是什么意思？
手风琴模式指同一时间只允许一个面板处于展开状态。当你点击展开某个问题时，其他已展开的问题会自动收起，保持界面整洁有序。
图标旋转是如何实现的？
加号图标的竖线在展开时通过 GSAP 旋转 90 度，与横线重合后视觉上变为减号；收起时再旋转回 0 度，配合缓动函数让切换自然顺滑。
动画卡顿了怎么办？
建议优先动画 transform 与 opacity 等合成属性，避免频繁触发重排。GSAP 内置了高效的渲染调度，通常能稳定保持 60fps 的流畅表现。
