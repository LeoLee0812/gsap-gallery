嵌套时间轴

真实项目里一条大时间轴动辄几十行，改一处全乱。正确做法是每个场景写成独立的小时间轴， 再用一条 master 把它们拼起来——每一段都能单独调试、单独复用。

// 每个场景是一个返回 timeline 的函数，可独立播放、独立调试
function scene1() {
  const tl = gsap.timeline();
  tl.from(".s1 .dot", { scale: 0, stagger: 0.1, ease: "back.out(2)" })
    .to(".s1 .dot", { scale: 1.4, yoyo: true, repeat: 1, stagger: 0.08 });
  return tl;
}

// master 用 .add() 把子时间轴拼起来，第二个参数还是位置参数
const master = gsap.timeline();
master.add(scene1())
      .add(scene2(), "-=0.2")   // 和上一段重叠 0.2s
      .add(scene3(), "+=0.1");

// 整条能变速：master.timeScale(2) 会同时影响所有子时间轴
