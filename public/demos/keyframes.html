关键帧 keyframes

同一个元素要连着走好几段（右 → 上 → 左 → 落回），不必写四条 tween， 一条 tween 里写 keyframes 就够，还能给每一段单独设 ease 和时长。

写法一 · 数组关键帧
每一项是一个状态，按顺序走。段与段之间可以各自设 duration、ease、delay。
gsap.to(box, {
  keyframes: [
    { x: 200, duration: 0.5 },
    { y: -60, duration: 0.4, ease: "back.out(2)" },
    { x: 0,   duration: 0.5 },
    { y: 0,   duration: 0.35, ease: "bounce.out" }
  ]
});
写法二 · 百分比关键帧
跟 CSS @keyframes 一个思路：按总时长的百分比定位，适合从设计稿翻译过来。
gsap.to(box, {
  duration: 2,
  keyframes: {
    "0%":   { x: 0,   y: 0,   scale: 1 },
    "30%":  { x: 200, y: -40, scale: 1.3 },
    "60%":  { x: 200, y: 40,  rotate: 180 },
    "100%": { x: 0,   y: 0,   rotate: 360, scale: 1 },
    easeEach: "power2.inOut"
  }
});
写法三 · 属性内联关键帧
直接给某个属性一个数组，GSAP 会在这些值之间依次补间。写抖动、脉冲最省事。
gsap.to(box, {
  duration: 1.6,
  x: [0, 180, 60, 220, 0],
  scale: [1, 1.35, 0.85, 1.2, 1],
  ease: "power1.inOut"
});

关键帧和时间轴不冲突：单个元素的多段连续变化用 keyframes 最简洁； 多个元素之间的先后编排才该上 timeline。
数组写法里 delay 表示与前一段的间隔，写负值就能让两段重叠。
