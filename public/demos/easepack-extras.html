EasePack · 四个特种缓动

除了 power / back / elastic 这些常规 ease，GSAP 还带了四个解决特定问题的特殊 ease。 平时用不上，但一旦遇到对应场景，它们能省掉几十行代码。

RoughEase 把平滑的曲线打碎成锯齿
做故障、抖动、老电视信号、打字机的不稳定感。它在原有 ease 基础上加随机噪点， points 控制噪点密度，strength 控制偏离幅度。点格子播放。
SlowMo 两头快、中间慢的「子弹时间」
文字滚动播报的经典解法：快速进场 → 中段慢到能看清 → 快速离场。 用普通 ease 做不到「中间停留」这件事，SlowMo 是专门为它设计的。
这段文字会在中间慢下来，让你有时间读完
SteppedEase 分段跳变，没有中间态
刻意丢帧的效果：秒针一格一格跳、像素风角色行走、逐帧动画。 注意它和 steps() 是同一套东西，写法上 steps(n) 更简洁。
ExpoScaleEase 缩放时保持视觉速度均匀
这是个很少人知道但很重要的问题：从 scale 1 放大到 5，用线性 ease 看起来是「先慢后快」的—— 因为人眼感知的是相对变化率。ExpoScale 修正了这个错觉。左右对比一下就明白了。
线性
ease: "none"　
看起来先慢后猛
ExpoScale
ease: expoScale(1, 5)　
全程视觉速度均匀
gsap.registerPlugin(EasePack);   // RoughEase / SlowMo / ExpoScaleEase 都在这个包里

// ── 故障抖动 ──
gsap.to(el, { x: 400, ease: "rough({ template: power2.out, strength: 2, points: 40, taper: 'out' })" });

// ── 子弹时间：linearRatio 0.7 表示中间 70% 的时间几乎不动 ──
gsap.to(el, { x: 400, ease: "slow(0.7, 0.7, false)" });
//                            ↑linearRatio ↑power ↑yoyoMode

// ── 分段跳变 ──
gsap.to(el, { x: 400, ease: "steps(8)" });

// ── 缩放专用：参数是起始和结束的 scale 值 ──
gsap.fromTo(el, { scale: 1 }, { scale: 5, ease: "expoScale(1, 5, power2.inOut)" });

ExpoScaleEase 的适用条件很明确：只有在 scale 变化幅度很大（比如 1 → 5、0.2 → 1）时才有意义。 从 1 放大到 1.1 这种小变化，用不用它看不出区别。
RoughEase 有个 taper 参数："out" 让抖动逐渐平息（收尾干净），"in" 反之， "both" 两头都收。做故障效果一般用 "out"。
SlowMo 的第三个参数 yoyoMode 设为 true 时，动画会「去了再回来」，适合做闪烁强调。
