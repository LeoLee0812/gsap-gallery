gsap.utils 实验台

这些不是动画，是做交互动画时天天要算的数学。全都挂在 gsap.utils 上，不用注册插件。 拖滑块看它们分别干了什么。

clamp(min, max, value)
把数值卡在区间内，超出就取边界。防止鼠标拖太远、滚动值越界。
mapRange(inMin, inMax, outMin, outMax, value)
把一个区间的值线性映射到另一个区间。滚动位置 → 透明度、鼠标 X → 旋转角 全靠它。
normalize(min, max, value)
把任意区间压成 0~1 的进度值。等价于 mapRange 到 [0,1]，写进度条时最顺手。
interpolate(a, b, progress)
在两个值之间取中间态。数字、颜色、甚至整个对象都能插值。
snap(increment, value)
吸附到最近的网格点。拖拽对齐、旋转吸附 15°、滚动吸附整屏都用它。在下方格子里移动鼠标。
wrap(min, max, value)
越界就绕回另一端，像贪吃蛇穿墙。无缝跑马灯、循环轮播的核心。
random(min, max, snapTo)
带吸附的随机数，也能从数组里随机抽一个。粒子、撒花、随机浮动的标配。
pipe(fn1, fn2, ...)
把多个函数串成一条流水线，前一个的输出喂给后一个。省掉层层嵌套的括号。
toArray(target)
把选择器 / NodeList / 类数组统统转成真数组，之后就能 map、filter、forEach。
unitize(fn, unit)　·　splitColor(color)
unitize 让上面那些纯数字工具能直接处理带单位的字符串；splitColor 把颜色拆成 RGB / HSL 数组。

省略最后一个参数 = 拿到一个可复用的函数。 比如 const clamp = gsap.utils.clamp(0, 100)，之后直接 clamp(x)。 在 mousemove、onUpdate 这类每帧调用的地方，这样写比每次传全参数更清晰也更省。
唯一的例外是 random()——它要拿可复用函数得把最后一个参数传 true，而不是省略。
