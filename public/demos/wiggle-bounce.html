CustomWiggle / CustomBounce

这两个插件解决同一类问题：把「抖动」和「弹跳」这种本来要写十几个关键帧的效果，压缩成一个 ease。 一行 ease 换掉一整条时间轴。点任意格子播放。

CustomWiggle · 抖动
指定抖几次和衰减方式，自动生成来回摆动的曲线。表单校验失败的抖动、图标提醒的摇晃、 按钮的调皮反馈，全都一行搞定。
CustomBounce · 弹跳（含挤压变形）
不只是「掉下来弹几下」——它还能同时生成一条配套的挤压曲线，让球落地时压扁、弹起时拉长。 这是让弹跳看起来「有重量」的关键，手写几乎不可能调准。
四个真实场景
这些就是 wiggle / bounce 在产品里最常出现的地方。

gsap.registerPlugin(CustomWiggle, CustomBounce, CustomEase);

// ── 抖动 ──────────────────────────────
CustomWiggle.create("shake", {
  wiggles: 6,           // 来回摆动几次
  type: "easeOut"       // easeOut | easeInOut | anticipate | uniform | random
});
gsap.fromTo(input, { x: -8 }, { x: 8, duration: 0.6, ease: "shake" });

// ── 弹跳 ──────────────────────────────
CustomBounce.create("myBounce", {
  strength: 0.6,        // 弹性强度 0~1，越大弹得越久
  squash: 2,            // 挤压程度，0 表示不生成挤压曲线
  squashID: "myBounce-squash"
});

// 位置用弹跳曲线，缩放用配套的挤压曲线，两条同时跑
gsap.to(ball,  { y: 300, duration: 1.6, ease: "myBounce" });
gsap.to(ball,  { scaleX: 1.4, scaleY: 0.6, duration: 1.6,
                 ease: "myBounce-squash", transformOrigin: "center bottom" });

抖动的幅度要克制。校验失败抖 6~8 像素就够了，抖到 30 像素就从「提示」变成「故障」了。
squash 是 CustomBounce 的灵魂。只有位置弹跳没有形变，看起来像个刚体在跳； 加上挤压拉伸，才有「弹力球」的质感——迪士尼动画十二原则里的 squash & stretch 就是这个。
两个插件都依赖 CustomEase，注册时要一起引入。它们现在都免费。
