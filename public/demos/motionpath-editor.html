MotionPath 进阶

拖动路径上的绿色锚点改变轨迹，动画会立刻跟着变。 重点看 autoRotate ——它让元素自动朝向前进方向，是「沿路径运动」看起来自然的关键。

gsap.registerPlugin(MotionPathPlugin);

// 写法一：跟随一条真实的 SVG path
gsap.to("#rocket", {
  duration: 4,
  ease: "none",
  motionPath: {
    path: "#path",         // 选择器、path 元素，或坐标数组
    align: "#path",        // 让元素坐标系对齐到这条 path 上
    alignOrigin: [0.5, 0.5],  // 元素的哪个点贴着路径（中心）
    autoRotate: true,       // 自动朝向前进方向 —— 关键
    start: 0, end: 1          // 只跑路径的某一段
  }
});

// 写法二：直接给一串坐标点，GSAP 自动拟合成平滑曲线
gsap.to(box, {
  duration: 3,
  motionPath: {
    path: [{ x: 0, y: 0 }, { x: 150, y: -80 }, { x: 300, y: 40 }],
    curviness: 1.5,     // 0 = 直角折线，越大越圆润
    autoRotate: true
  }
});

// 开发时用 MotionPathHelper 可以在页面上直接拖控制点调路径：
// MotionPathHelper.create("#rocket");  // 调完把生成的 path 复制走，上线前删掉

autoRotate 是这个插件的灵魂。关掉它，火箭会保持水平地「平移」过整条曲线，非常假； 打开它，元素会像真的在飞。
autoRotate 还能传数字做角度偏移——比如你的图标本身是朝上画的（而不是朝右）， 就传 90 或 -90 把它掰正。这是最常见的踩坑点。
alignOrigin 决定「元素的哪个点贴着路径」：默认是元素左上角，几乎总是要改成 [0.5, 0.5]（中心）。 做「小车沿路行驶」时则该用 [0.5, 1]（底部中心），让轮子贴着路。
MotionPathHelper 是配套的开发工具，在页面上直接拖出路径再把结果复制到代码里，比手写 SVG path 快得多。
