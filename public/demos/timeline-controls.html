Timeline 播放控制台

时间轴不是「播完就完」——它是一个可以随时暂停、倒放、变速、跳到任意一秒的对象。 这是 GSAP 相对 CSS 动画最大的优势。

// 时间轴创建时就带 defaults，子动画统统继承
const tl = gsap.timeline({ paused: true, defaults: { duration: 0.6, ease: "power2.inOut" } });

tl.addLabel("intro")
  .from(".card", { scale: 0, rotate: -180, stagger: 0.12 })
  .addLabel("spread")
  .to("#c1", { x: -80, y: -60 })
  .to("#c2", { y: -90 }, "<")
  .to("#c3", { x: 80, y: -60 }, "<")
  .addLabel("gather")
  .to(".card", { x: 0, y: 0, rotate: 360 })
  .addLabel("outro")
  .to("#title", { opacity: 1, y: 10 });

// 之后就能随意操控：
tl.play(); tl.pause(); tl.reverse();
tl.progress(0.5); tl.timeScale(2); tl.seek("gather");
