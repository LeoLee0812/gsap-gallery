调试标记线

toggleActions 四态

ScrollTrigger 有四个进出边界的时机，toggleActions 就是按顺序给这四个时机各指定一个动作。 往下滚，再往回滚，对比四种配置的差别——差异全在「回滚时会不会复原」。

顺序：onEnter · onLeave · onEnterBack · onLeaveBack 可选动作：play / pause / resume / reset / restart / complete / reverse / none
↓
toggleActions: "play none none none"　（默认值）
进场播放，之后什么都不管
最常用。滚进来播一次动画，滚出去、滚回来都不再触发。适合「内容入场」这类一次性效果。
1
toggleActions: "restart none none reset"
每次滚进来都重播
往上滚出顶部边界时 reset 回初始状态，再滚下来就是全新的一遍。适合演示页、需要反复看到动画的场景。
2
toggleActions: "play reverse play reverse"
跟着滚动方向来回播
进入正播、离开倒播。元素始终跟着你的滚动方向进出，是最「跟手」的一种，适合导航栏、侧边元素。
3
toggleActions: "play pause resume reset"
离开就暂停，回来接着播
离开视口时冻结当前帧（省性能），回到视口从冻结处继续。长循环动画、视频式动效常用这套。
4
once: true
播一次就把自己销毁
不是 toggleActions，而是独立选项。触发一次后 ScrollTrigger 自动 kill 掉，不再占用滚动监听——长页面里有几十个入场动画时，这是重要的性能优化。
5
往回滚，对比它们的差别 ↑
右上角打开 markers 能看到 start / end 的实际位置——调 ScrollTrigger 时几乎离不开它，上线前记得关掉。
